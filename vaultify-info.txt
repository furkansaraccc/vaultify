2. **JWT (JSON Web Tokens)**: A method of securely transmitting information, used for authentication with access and refresh tokens.
3. **Rate Limiting**: A technique to prevent brute force attacks by limiting the number of requests per endpoint.
4. **AES-GCM (Advanced Encryption Standard - Galois/Counter Mode)**: A symmetric encryption algorithm ensuring data confidentiality and integrity.
5. **PBKDF2 (Password-Based Key Derivation Function 2)**: A key derivation function used to securely generate encryption keys.
6. **Role-based Access Control (RBAC)**: A security mechanism for managing permissions, allowing for different levels of access (read, write, admin).
7. **Audit Logging**: The practice of recording security events, such as logins and password updates, for compliance and forensic purposes.
8. **TLS (Transport Layer Security)**: A cryptographic protocol used to secure data transmission over the network.
9. **JWT Token Metadata**: Device-bound metadata like IP addresses and user agents to secure token usage.
10. **SQLAlchemy ORM (Object-Relational Mapping)**: A Python library for managing the database structure, including users, tokens, and logs.
11. **Connection Pooling**: A technique used to manage multiple database connections efficiently, improving performance.
12. **Caching**: Storing frequently accessed data in memory to improve scalability and performance.
13. **Soft Deletion**: A database practice that marks records as deleted without permanently removing them.
14. **Pagination**: A technique to handle large datasets by breaking them into smaller, more manageable chunks.
15. **NIST (National Institute of Standards and Technology)**: Refers to the compliance requirements for password policies, including strength and complexity.
16. **HSTS (HTTP Strict Transport Security)**: A web security policy to enforce HTTPS and prevent certain types of attacks.
